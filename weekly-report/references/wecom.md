# 企业微信（wecom-cli）— 实验性

> ⚠️ 实验。企业微信有开放服务端 API（通讯录 / 应用消息 / 客户联系 / 审批 / 日历 / 微盘），但**读员工聊天记录必须由企业开通「会话内容存档」**（配存档范围 + 密钥 + SDK，并履行员工/客户告知同意）。**个人账号 / 临时演示拿不到聊天历史**——这是硬限制，别承诺能读。

## 能做 / 不能做
- ✅ 企业自建应用范围内：通讯录、应用消息（发）、日历、审批、客户联系等服务端 API（opencli 有 `wecom-cli`）。
- ❌ 个人拿自己/员工历史聊天：无「会话内容存档」拿不到；hook / 协议破解违规。

## 初始化
只在用户明确选企业微信、且是企业管理员或已开通对应能力时尝试；否则标 `skipped` 并说明“读聊天需企业会话内容存档，个人拿不到”。走 `wecom-cli` 的登录/授权流程；管理员未开通相应能力就标 `pending`，不假装完成。
