# 企业微信（wecom-cli）能力边界——当前待接入

> 当前版本的企业微信 IM 路径只有「大圆」总结，见 `wecom-daiyuan.md`。本文件记录官方 CLI 的能力边界，**不是当前版本的安装或授权指令**。

## 当前版本怎么处理

- **普通 IM**：个人账号不能直接读取员工聊天历史。当前折中方案是让企业微信原生 AI「大圆」先总结，再作为 `source_type=summary`、`evidence_level=medium` 的二手证据单列确认。
- **企业会话内容存档**：需要企业开通存档范围、密钥和 SDK，并履行员工 / 客户告知同意；当前 Skill 不自动配置这条企业级路径。
- **非 IM 数据域**：官方 [`wecom-cli`](https://github.com/WecomTeam/wecom-cli) 已提供邮件、文档、待办、日历、会议、微盘和通讯录等能力，但当前 Skill 尚未完成连接、字段归一化和只读试取验证，因此不进入正式来源矩阵。

用户选择企业微信非 IM 数据域时，当前版本应标为 `skipped`，说明“官方 CLI 有相应能力，但本 Skill 尚未接入”；**不要执行 `wecom-cli` 安装、登录或授权，也不要声称已经连接**。

## 未来接入门槛

只有同时满足下面三项，才能把对应数据域加入正式来源矩阵：

1. 在主 Skill 中声明明确的数据域、最小权限和字段映射。
2. 完成官方登录流程，并用当前用户身份做一次真实的只读试取。
3. 将结果归一为个人证据，验证身份、时间窗、分页和 `collection_complete` 语义。

未满足时保持 `skipped`；不通过安装或扩权绕过来源确认。
